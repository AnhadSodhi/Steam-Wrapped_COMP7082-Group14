# Steam Wrapped Frontend

The frontend is a Next.js application that lets users search public Steam
profiles and explore their gaming habits, favourite genres, playtime, and
statistics.

## Getting started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The frontend proxies API
requests to `http://localhost:3001` by default. Set `BACKEND_URL` in `.env` to
use a different backend host.

See the [repository README](../README.md) for the full local setup, including
the backend and Steam API key configuration.
